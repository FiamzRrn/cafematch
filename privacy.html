Kebijakan Privasi

CafeMatch adalah demo sistem pakar rekomendasi kafe di Kota Semarang. Mesin inferensi dan snapshot basis pengetahuan berjalan di browser.

Data yang disimpan di perangkat

Browser menyimpan preferensi konsultasi dan kafe favorit di local storage. Koordinat lokasi perangkat tidak disimpan. Hapus data tersimpan melalui pengaturan penyimpanan situs di browser.

Pemrosesan lokal

CafeMatch tidak menggunakan Google Maps atau Places API. Peta dibuat dengan Leaflet dan React Leaflet, sedangkan peta dasarnya memuat tile dari server OpenStreetMap. Permintaan tile dikirim dari browser dan dapat menyertakan alamat IP serta bagian peta yang diminta. Lihat kebijakan penggunaan tile OpenStreetMap.

Akses lokasi perangkat bersifat opsional. Browser hanya meminta izin setelah pengguna menekan tombol “Gunakan lokasi saya”. Koordinat dipakai sementara di browser untuk menentukan titik tengah peta dan menghitung jarak; koordinat tidak disimpan atau dikirim ke server aplikasi. Geolocation memerlukan izin browser dan konteks aman seperti HTTPS atau localhost.

Basis pengetahuan kafe adalah snapshot statis. Tautan sumber, termasuk Google Maps dan direktori tempat, hanya dibuka bila dipilih pengguna; situs tujuan dapat menerima data koneksi sesuai kebijakannya sendiri.

Sumber data kafe
